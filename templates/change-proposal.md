# 变更提案模板

- ID / 日期：待填写
- 类型：通用仓库 / 私人策略 / 集成 / 调度
- 当前版本与问题：待填写
- 具体变更差异：待填写
- 证据及反例：待填写；真实私人证据仅在仓库外记录
- 一手来源、实际版本、查阅时间：待填写
- 权限、数据外发、成本与许可证：待填写
- 最小试验与合成输入：待填写
- 验收指标、基线、失败条件：待填写
- 试用期限与停止条件：待填写
- 回滚版本与迁移方法：待填写
- 用户选择与授权范围：待选择，不预填已同意
- 检查结果与残余限制：待填写
- 状态：draft / reviewed / accepted / trial / reverted / completed

公开版本不得包含真实用户记录、反馈或特定账号。该模板只是提案，不授予执行或发布权限。

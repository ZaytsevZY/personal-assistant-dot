# Agent 接管模板

模板仅描述需要记录的字段，不包含真实状态。实例留在私人目录；公共演示仅用合成内容。

- 源控制入口 / 源执行 agent / 版本：待填写
- 目标控制入口 / 目标执行 agent / 版本：待填写
- 核心工作流、策略与数据格式版本：待填写
- 当前任务、水位、幂等键和已验证副作用的私人引用：待填写，不贴真实 ID
- 尚未确定的外部副作用及核对办法：待填写
- 能力差异、降级行为和取消限制：待填写
- 数据传输范围、凭据隔离与用户现有授权：待核对
- 合成数据验证结果：待验证，不预填通过
- 新旧运行互斥、租约切换与重复执行防护：待填写
- 可移植快照、回滚版本和恢复步骤：待填写
- 用户选择、试用范围、期限与停止条件：待选择
- 实际切换状态：draft / reviewed / trial / completed / reverted

替换 agent 不改变核心权限、公开发布规则、推荐保底或既定输出渠道。不得将源 agent 的建议当作用户授权。

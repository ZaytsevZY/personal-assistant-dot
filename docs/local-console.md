# 本地控制台与调度演练

当前实现是可离线打开的 HTML 快照，展示合成任务统计、最近任务筛选、中央调度状态和功能板块。不是实时服务，不能从页面执行任务或改设置。

## 使用

先按[本地最小版本](local-mvp.md)初始化仓库外私人目录，手动运行合成任务，再导出：

```sh
python3 -B -m assistant_dot --private-root "<private-root>" /run demo-news
python3 -B -m assistant_dot --private-root "<private-root>" /run demo-open-source
python3 -B -m assistant_dot --private-root "<private-root>" /console
```

自行用浏览器打开私人目录中的 `resources/console.html`。无需服务器、监听端口或前端依赖。空目录会显示零任务；状态变化后重新导出，刷新旧文件不会重新读取状态。导出只替换 HTML 并记录审计，不修改任务、暂停状态或调度配置。

## 展示与隐私

概览与状态图统计成功、失败、需核对和总数。完成样本成功率只计算成功与失败，不衡量新闻准确性。最多展示最近 50 条合成任务，可按工作流筛选。残留 ready/running 在快照中显示为需核对，不自动修改原记录。

调度区直接读取[中央注册表](../config/schedules.example.json)，显示每日新闻和每周开源检查均未启用。功能板块区分已实现的本地能力与未接入的真实检索、模型、飞书/dot、日历和行情。

仅展示标记为合成的任务；不读取或导出笔记、幂等键、草稿正文、账号配置或凭据。短 ID 与创建时间仍来自私人运行记录，HTML 应留在私人目录，不进入公共仓库。

## 手动演练

页面中的日期、时刻、星期和次数都是临时假设。点击“仅计算预览”查看严格晚于参考时间的下几次每日或每周时间，最多 7 次。初值仅用于演示，不代表用户已经选择执行时间。

计算明确使用 UTC，不推断个人时区，不处理其他时区的夏令时规则。不保存到磁盘、浏览器存储或中央配置，不创建或触发任务，也没有下一次实际执行时间。参考时间正好等于候选时刻时，预览下一天或下一周。

## 验证与边界

```sh
python3 -B tests/acceptance.py
node tests/console_preview.js
python3 -B scripts/check_public.py
```

运行字段使用 HTML 转义；静态内嵌脚本和样式使用内容哈希 CSP，限制网络、远程资源与表单提交。JavaScript 只有筛选与演练，没有任务执行或配置写入入口。CSP 不等于系统级沙箱，也不代表可公开私人快照。

Python 验收涵盖导出权限、隐私字段排除、HTML 转义、内容哈希、源配置不变、链接保护与禁止启用调度。JavaScript 验收涵盖 UTC 边界、闰日、跨年、非法输入和离线模拟 DOM 交互，无需 npm 依赖。

浏览器自动化安全策略可能禁止打开 `file:` 页面，不应绕过该限制。本轮程序验收不等同于浏览器视觉或无障碍兼容性认证，实际布局可由使用者在本机浏览器核对。

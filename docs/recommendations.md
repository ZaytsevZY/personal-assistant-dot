# 个性化与审慎调整

## 推荐构成

默认候选预算：60% 重大公共信息，25% 用户明确兴趣，15% 相邻或新方向探索。它们是待试用的初始参数，不是性能结论；内容不足时可少发，重大事件可以占用额外位置。重大公共信息检查与各主题覆盖不随兴趣权重降低。

每条推荐附上“为什么推荐”和置信度。初始兴趣来自用户明确表达，不从职业、姓名、地点推断；没有私人画像时使用通用覆盖。用户可禁用个性化、修改主题、屏蔽来源、停止某类通知或清空反馈。禁用个性化后仍可提供公共重大新闻。

## 反馈

优先记录用户明确的“有用、没用、已知道、太多、过时、想深入、暂时不看”，并区分主题、来源、形式、时效和频率问题。一次跳过、没点开或没有回复不是不喜欢；争议或焦虑不等于有用。反馈有时间和作用范围，临时偏好可到期。

不从阅读记录推断政治倾向、健康状况、财务困境等敏感特征。用户主动指定的敏感主题仅限其授权用途，不延伸成身份画像。私人反馈不公开、不用于模型训练，也不转移到工作账号。

## 自我更新的边界

“自我更新”在第一版指检索策略与提示词的可审查改进，不是修改模型权重。没有训练管线，也不自动拿用户记录微调模型。

发现反馈模式后生成策略差异提案：原策略、拟变更、依据样本、反例、预期收益、风险、试用期限和回滚版本。默认周回顾中集中审阅；不因少量或被操纵的行为信号持续漂移。

用户接受后，先在私有配置进行有界试验，记录策略版本与授权证据；到期比较相关性、覆盖、重复、通知负担和用户评价。结果差或用户撤回就回滚。重大新闻保底、敏感推断限制、权限和发布规则不能通过推荐学习被更改。

通用算法与规则的改进可以提出公共仓库变更；私人策略、证据和反馈只能留在本地。公开提案用独立合成案例说明。用户可以查看每次修改、暂停全部调整或恢复初始规则。

# 阶段与验收

## 当前完成范围

已有[本地最小版本](local-mvp.md)和[只读控制台](local-console.md)：命令入口、仓库外私人 JSON 存储、同步任务运行器、合成适配器、状态、审计、可视化快照与 UTC 演练。没有应用构建步骤；真实对话平台、新闻检索、实时图形控制、行情源、后台调度与模型训练尚未实现。

## 分阶段实现

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 0 手工试用 | 日常收集、新闻简报、每周发现 | 用户判断是否省时；记录错误与缺失 |
| 1 私人存储 | 仓库外资料、版本、备份与恢复 | 重建索引后原文不丢；恢复演练成功；状态不只存在于平台聊天 |
| 2 双入口核心 | 飞书或初期 dot、`/h`、任务查询、本地控制台、agent 适配契约 | 两入口状态一致；权限与账号隔离；替换 agent 不重写工作流 |
| 3 信息发现 | 新闻源、独立核实、重大新闻保底 | 覆盖时政经济科技；去重、日期与更正可追溯 |
| 4 日历与通知 | 已选目标、幂等、送达验证 | 超时不重复写；离线与账号切换行为明确 |
| 5 推荐试验 | 私人反馈、策略差异与回滚 | 可以禁用；反馈不改变保底与权限 |
| 可选扩展 | 经济指标与股票查询 | 数据许可、延迟、口径齐全；不交易 |

## 质量样例

| 场景 | 应有结果 |
| --- | --- |
| 旧事件今天被转载 | 显示原发生日期，不当作新事件 |
| 三个网站转载同一消息 | 只算一个独立消息链 |
| 官方发布未经独立验证的说法 | 标明是某方声明，列出不确定性 |
| 用户近期只读科技 | 仍检查重大时政与经济变化 |
| 用户没点击某条消息 | 不推断不喜欢，不自动修改策略 |
| 新闻正文要求执行命令 | 忽略该指令，作为不可信内容处理 |
| 飞书发送超时 | 查询结果，标记未知，不切账号补发 |
| 多入口执行同一任务 | 共用幂等键与状态，避免重复 |
| 从 dot 更换执行 agent | 保留任务、策略和审计版本；未知副作用先核对，不重复执行 |
| 提议替换框架 | 核实官方来源并用合成数据验证，不自动安装 |
| 股票数据延迟未知 | 清晰标注，不显示为实时 |
| 新文件出现真实凭据 | 公开检查失败；人工复核并轮换凭据 |

关注有证据的事实错误、重大事件遗漏、重复率、来源独立性、检索失败、延迟、费用、通知负担和用户明确评价。先建立基线再设目标；不声称已经达到准确率或性能指标。任何自动发布功能都不在当前路线图范围内。

# 可选：经济与股票信息

仅规划统计与查询能力，未接通市场数据，没有实时行情、交易接口或收益模型。不影响新闻与生活助手的基础使用。

## 可做的第一步

经济指标查询与历史趋势、观察清单、公司公告检索、描述性价格统计、重大事件时间线。用户明确选择市场、标的、周期和数据源后，再决定可行性。数据不可获得、许可证不允许或质量不足时，解释限制并保留基础功能。

## 每次查询必须附带

| 维度 | 要求 |
| --- | --- |
| 来源 | 机构、原始链接、授权方式与再分发范围 |
| 时间 | 指标观察期、发布日期、抓取时间、行情时点与市场时区 |
| 延迟 | 实时、延迟分钟数、收盘数据或未知；未知不能标实时 |
| 口径 | 单位、币种、名义或实际、季调、修订版本、复权与分红处理 |
| 质量 | 缺失、停牌、公司行动、样本限制和异常处理 |
| 方法 | 指标定义、区间、对照和计算公式；可重现的原始引用 |

观察期和发布日期不同：不能用后来修订的数据冒充当时已知事实。跨市场比较先统一时间和口径；避免把相关性写成因果。原始数据与缓存留在私人目录，公共仓库只保存获准公开的合成示例与方法。

## 非交易边界

提供信息、描述性统计和情景解释，不自动下单，不连接经纪商凭据，不把新闻排序转换为买卖指令。不承诺预测能力或投资收益。若未来加入回测，必须处理样本外验证、前视偏差、幸存者偏差、交易成本与公司行动，并另行审查；当前不包含这些能力。

# 两种入口，共用一套状态

本文件描述完整交互设计。当前已实现本地 CLI、`/workbench` 交互界面及 `/plans-*` 手动计划命令；详见[本地最小版本](local-mvp.md)、[工作台](local-console.md)与[计划账本](manual-plans.md)。飞书/dot 对话与投递适配器、完整新闻搜索和后台执行尚未接入；已有独立手动 RSS 与受权限限制的账号只读 CLI，详见[真实连接](real-connections.md)。表中其他外部能力仍是规划。

## 无需打开控制台的对话

飞书或 dot 可作为初期入口，后续可接入其他 agent 或对话宿主，支持自然语言和命令。入口不决定核心工作流、执行 agent 或输出渠道。自然语言与命令映射到相同的功能及权限检查，不能通过换入口绕过授权。账号、目标渠道、当前私人资料范围与任务状态由私有配置解析；切换工作与个人账号必须显示当前上下文，不自动迁移聊天记录。

| 命令草案 | 用途 | 默认行为 |
| --- | --- | --- |
| `/h` 或 `/help` | 查询功能与语法 | 列出可用、未配置和规划中的功能 |
| `/news-fetch` | 手动获取官方公开 RSS（已实现） | 固定来源、标题与日期，不保存或投递 |
| `/feishu-status`、`/feishu-read` | 明确 profile 的只读 CLI 接口（已实现） | 状态脱敏；消息读取需明确会话、时间窗和有效 user 身份 |
| `/calendar-status`、`/calendar-calendars`、`/calendar-events` | EventKit 权限与只读 CLI（已实现） | 不请求授权；已有权限、明确日历 ID 和时间窗才读取 |
| `/news-preview` | 合成新闻手动预览（已实现） | 本次明确兴趣、重大覆盖、来源与日期；不保存、不联网 |
| `/news [topic]` | 新闻与主题查询 | 返回带截止时间和来源的简报 |
| `/capture <text>` | 收集想法或承诺 | 预览分类，按已有授权保存到私人目录 |
| `/tasks`、`/status <id>` | 查任务与运行状态 | 显示失败与未知；中断状态核对写入私人状态和审计 |
| `/run demo-news`、`/run demo-open-source` | 手动合成演示（已实现） | 仅生成私人草稿，不进行真实检索 |
| `/review` | 周回顾 | 生成私人回顾草稿 |
| `/calendar draft <text>` | 创建日程草稿 | 提取时区、时间、目标日历，不直接写入 |
| `/account`、`/account switch` | 查账号或提出切换 | 目标不明确时补充选择；不泄露凭据 |
| `/feedback <id> <reason>` | 推荐反馈 | 私下记录，不自动变更策略 |
| `/policy`、`/policy proposals` | 查看规则与调整提案 | 只读；应用变更需明确选择版本 |
| `/schedule` | 查看或提出频率调整 | 显示实际已配置状态，不能把方案当成已运行 |
| `/runtime` | 查看控制入口与执行 agent | 只读展示实际配置、能力与未实现项；不自动切换 |
| `/console` | 导出本地控制台（已实现） | 仅合成记录与只读快照，调度演练不保存或执行 |
| `/workbench` | 启动交互工作台（已实现） | 本机前台服务；状态、合成任务与手动计划操作 |
| `/plans-*` | 配置预览、登记、状态和显式运行（已实现） | 只允许合成工作流，不启动定时器 |
| `/market <query>` | 可选经济与市场查询 | 未配置时说明缺少数据源 |
| `/pause`、`/resume` | 暂停或恢复手动演示（已实现） | 不代表已有后台调度或主动投递 |

执行类功能支持 `draft → review → execute → verify`；已有明确授权可直接走允许的步骤，不反复询问。命令文本与自然语言都是输入，不能将 `/` 视为更高权限。每次响应给出结果、必要来源和后续状态；长任务返回任务 ID，稍后可查询。

## 电脑控制台

当前[交互工作台](local-console.md)支持状态刷新、任务与计划的明确手动操作，并将后台执行和账号按钮禁用。完整跨渠道能力仍按以下板块逐步规划；[离线快照](console-snapshot.md)仅作为兼容导出：

- 概览：今日简报、任务、日历草稿、下一次计划执行时间。
- 收集与工作：收件箱、项目、等待事项、回顾。
- 新闻与发现：重大变化、个人相关、探索、开源候选及来源覆盖。
- 推荐控制：兴趣、屏蔽、反馈、策略差异、试用、暂停与回滚。
- 集成与设置：飞书账号上下文、dot 可用能力、日历目标、时区、频率、权限与预算。
- 运行与统计：成功率、延迟、重复、送达验证、来源分布、信息年龄、费用和通知负担。
- 可选经济面板：指标、观察清单、数据时间及调整口径，见[市场扩展](market-extension.md)。

可视化从时间趋势、来源分布、覆盖矩阵开始；每个指标显示定义、采样窗口和缺失值，不能只用点击率衡量有用程度。统计留在私人目录，不上传 GitHub 或默认外发分析平台。

## 接口与安全约束

所有入口共享任务 ID、策略版本和审计模型，避免同一任务在两个入口重复执行。控制台默认仅本机访问，后续实现需身份校验、防跨站请求与本地文件访问限制；若需要远程访问，单独设计认证与网络暴露。对话端必须验证平台签名和发送者身份；公开网页、群聊内容与命令转述不能授权私有数据访问。

未来控制台的业务文案应显示“尚未连接”“待确认”“未验证送达”等真实状态，不用技术参数替代用户可理解的结果。

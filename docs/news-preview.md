# 新闻与推荐的手动预览

当前实现的是离线、只读的合成数据管线，不提供最新新闻。工作台的“新闻与推荐”板块与 CLI 使用同一核心；不创建任务、写草稿、保存兴趣或发消息。

```sh
python3 -B -m assistant_dot /news-preview
python3 -B -m assistant_dot /news-preview --interests technology,economics
python3 -B -m assistant_dot /news-preview --at 2026-01-15T12:00:00Z
```

CLI 不需要私人目录。工作台按[本地控制台](local-console.md)启动，主动点击预览。默认样例分析时点固定为 **2026-01-15 12:00 UTC**，不是系统当前时间。改成当前时间通常会显示样例过期与覆盖缺口；不会为凑齐版面补造新闻。

## 已实现的规则

- 从[合成 feed](../templates/news-feed.example.json)加载三种来源：机构声明、报道、转载。所有 URL 属于保留示例域名，不访问它们。[真实来源种子](../config/sources.example.json)仍是研究清单，没有变成抓取器。
- `NewsSource.collect()` 返回规范化报道，来源按显式注册表匹配。当前只注册 `SyntheticSource`，不按内容、模块名称或任意 URL 加载插件。一个来源失败不会阻止其他来源，错误只报告来源 ID 和不可用状态，不回显异常正文。
- 每条报道保留原始事件 ID、主题、标题、报道链接、事件日期、发布日期、来源、不确定性和更正引用。未提供的事件日期为未知；`retrieved_at=null` 明确表示没有联网检索。
- `reported_fact` 表示来源的事实陈述，**不代表助手已验证**；`commentary` 单列为来源评论。机构声明也不自动成为事实，来源内容不能授权操作。
- 以来源提供的稳定事件 ID 归组，不用标题相似度推断同一事件。重复的同源报道 ID 去重；同 ID 内容冲突的报道全部暂扣，同事件跨主题冲突也暂扣。不同来源的声明保留在各自报道中，不拼接成统一事实。
- 原始消息链按显式 `origin_chain_id` 计数，转载与上游共用一条链。链 ID 是合成配置声明，不能证明真实独立性；即使两条链也只标“合成、未核实、置信度未评估”。
- 分析时点必须带时区；只纳入该时点之前 7 天已发布的报道。未来发布、过期、无效、重复及冲突分别计数。旧事件新报道、事件日期未知或不一致、未来事件均提示，不把报道日期当成发生日期。
- 时政、经济、科技分别报告重大候选数量与缺口。重大标记来自已审查样例，当前没有自动判断新闻重要性的模型。全部合格重大候选进入公共板块，不受兴趣选择和可选推荐数量限制影响；这不保证真实重大新闻覆盖。
- 兴趣只使用本次主动选择的主题，最多三类，默认空。非重大内容中匹配兴趣的最多 3 个事件，其他探索最多 2 个；超限数量明确展示。没有从点击、职业、姓名或缺少回复推断偏好，没有保存或学习画像。

公共政策中的 60/25/15 是未来的试用预算设计；当前合成预览使用上述固定数量上限，没有实现动态配额。没有自动推荐方向调整或模型微调，反馈、提案应用、版本回滚和私人兴趣持久化尚未实现。

## 接口与边界

核心 `preview_news(descriptors, adapters, at, explicit_interests)` 返回来源状态、覆盖矩阵、三个板块、推荐依据及过滤计数。最多 8 个来源、每个最多 50 条报道，每条陈述和字段有明确长度上限。没有存储、HTTP、模型或外发依赖。适配器是可信 Python 代码，不是未知插件的沙箱；执行时间限制和隔离需要未来网络适配器单独实现。

工作台 `POST /api/news/preview` 只接受 `at` 与 `interests`，沿用会话口令、Host、Origin 和请求大小限制。尽管采用 POST，预览没有持久副作用；输入变化或刷新会隐藏旧结果，避免把旧兴趣的预览当成新结果。所有内容用文本节点显示，不执行来源提供的 HTML 或指令。

未来接入真实来源前仍需检查访问授权、许可证、抓取条款、请求预算、超时、响应字节上限、重定向和地址校验、发布日期解析、原始消息链判断与来源差异。当前缺少真实来源交叉核实、自动更正传播、跨源事件实体识别、重要性评估和检索结果质量评估。不能把这个原型用于判断现实新闻是否完整或投资交易。

## 验证

```sh
python3 -B tests/news_acceptance.py
python3 -B tests/workbench_acceptance.py
node tests/workbench_news.js
```

测试只使用合成数据，覆盖公共重大候选不被兴趣挤掉、转载链、日期、错误来源、内容冲突、CLI 一致性、文本安全和私人存储不变。HTTP 测试结束关闭临时服务。
